# Robert Yenji - Portfolio Website

A modern, professional portfolio website showcasing cybersecurity engineering and AI integration expertise.

## Features

- **Modern Design**: Clean, dark-themed interface with gradient accents
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Fade-in effects, parallax scrolling, and interactive hover states
- **Performance Optimized**: Fast loading with debounced scroll handlers
- **Interactive Elements**:
  - Animated statistics counters
  - Card tilt effects on hover
  - Smooth scroll navigation
  - Mobile-friendly hamburger menu
  - Scroll-to-top button

## Sections

1. **Hero Section**: Eye-catching introduction with key statistics
2. **About Section**: Personal story and professional journey
3. **Numbers Section**: Key achievements and metrics
4. **Services Section**: Five main service offerings with detailed descriptions
5. **Education Section**: Academic credentials
6. **Contact Section**: Multiple ways to get in touch
7. **Footer**: Quick links and tagline

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript**: Vanilla JS for interactivity and animations
- **Google Fonts**: Inter font family

## Design Inspiration

Inspired by modern Framer templates with:
- Dark color scheme with blue-purple gradients
- Large, bold typography
- Spacious layouts with ample whitespace
- Micro-interactions and hover effects
- Professional yet approachable aesthetic

## Getting Started

Simply open `index.html` in a web browser to view the portfolio website.

### For Development

1. Clone the repository
2. Open `index.html` in your preferred browser
3. Edit the content in `index.html`
4. Customize styles in `styles.css`
5. Modify interactions in `script.js`

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## Performance Features

- Intersection Observer API for efficient animations
- Debounced scroll handlers
- Optimized CSS with minimal repaints
- Smooth 60fps animations

## Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --bg-primary: #0a0a0a;
    --accent-primary: #3b82f6;
    --accent-secondary: #8b5cf6;
    /* ... */
}
```

### Content
Update text directly in `index.html` or modify the content sections.

### Animations
Adjust animation timing and effects in `script.js` and `styles.css`.
