# Image Assets

Please add the following images to this directory:

1. **logo.png** - Your yellow/gold logo with "UR" initials and "ROBERT YENJI" text
   - Recommended size: 500x200px or similar (will scale automatically)
   - Format: PNG with transparent background preferred

2. **profile.jpg** - Your professional headshot photo
   - Recommended size: 800x800px or larger (square aspect ratio)
   - Format: JPG or PNG
   - The CSS will apply automatic dark theme blending (grayscale effect with blue tint)

Once you add these images, the website will display them automatically.
